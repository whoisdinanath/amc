# amc

Project page for **CNN-LSTM Hybrid Architecture for Over-the-Air Automatic Modulation Classification using SDR** (Journal of Innovations in Engineering Education, 2025).

- Page: https://whoisdinanath.github.io/amc/
- Paper: https://doi.org/10.3126/jiee.v8i1.82136
- Code: https://github.com/whoisdinanath/amc-using-cnn-lstm

Plain HTML and CSS with no build step; GitHub Pages serves the `main` branch. Search and citation metadata are in the `<head>` of `index.html`, `sitemap.xml` lists the page for search engines, and `llms.txt` summarizes the paper for language models. `python scripts/figures.py` redraws the architecture figures and the Method equation (needs LaTeX and dvisvgm).
